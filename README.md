# Pathfinder

Превращай обычные прогулки в исследование собственного города.

Мобильный GPS-трекер в стиле «тумана войны», созданный на React Native (Expo). Карта вокруг скрыта до тех пор, пока ты сам не пройдёшь или не проедешь по этим улицам, дворам и тропам.

## Возможности

- **Механика «тумана войны».** Неизведанные районы скрыты, карта открывается по мере движения.
- **Онлайн и офлайн карты.** Карты OpenStreetMap для повседневных прогулок и возможность заранее скачать регион для работы без интернета.
- **Фоновый трекинг.** Запись маршрута продолжается при заблокированном экране.
- **Настройки оформления.** Светлая и тёмная темы и несколько акцентных цветов.
- **Без рекламы и аналитики.** Никаких платных подписок и скрытых трекеров.

## Установка

1. Открой [страницу релизов](https://github.com/xLeSniKx/Pathfinder/releases) и скачай последний `PathFinder.apk`.
2. Сверь SHA-256 скачанного файла с контрольной суммой в описании релиза.
3. Разреши установку из неизвестных источников в настройках Android и установи APK.

## Сборка из исходников

Нужны Node.js (LTS), Android Studio и JDK 17.

```bash
git clone https://github.com/xLeSniKx/Pathfinder.git
cd Pathfinder
npm install
npx expo run:android
```

Для релизной сборки:

```bash
cd android
./gradlew assembleRelease
```

Готовый APK появится в `android/app/build/outputs/apk/release/`.
